### Security

- [github-security-overview](https://github.com/yann-p/github-security-overview): a Python CLI that lists GitHub security advisories across one or more organizations, one per line, sortable and filterable by status, age and severity.
- [jupyter-security-inventory](https://yann.md/jupyter-security-inventory/) ([repo](https://github.com/Yann-P/jupyter-security-inventory)): a catalog of Jupyter's public, non-archived repositories, each classified by kind and annotated with usage and security-relevant details.

### CSS

- [Header size interpolation](/html/headers): AI-built tool to help optimize the font size steps in headers
